# Web Admin (React MVP)

Админка переведена на React (`web/`) + API на Go (`cmd/web`).

## Локальный запуск (через Docker)

1. Убедись, что в `.env` заполнены параметры БД и `BOT_TOKEN` (если запускаешь бота).
2. Подними сервисы:

```bash
docker compose up -d --build db web frontend
```

3. Открой React UI:

`http://localhost:5173`

4. API доступен по адресу:

`http://localhost:8080/api/groups`

## Локальный запуск (без Docker для frontend)

1. Подними backend API:

```bash
docker compose up -d --build db web
```

2. Запусти фронт локально:

```bash
cd web
npm install
npm run dev
```

3. Открой:

`http://localhost:5173`

## Что реализовано

- Список групп.
- Выбор группы и просмотр текущих настроек.
- Создание/удаление шаблонов.
- Создание/удаление расписаний.
- Создание событий.
- Привязка шаблона к событию.
- Обновление/очистка стоимости события.

## Важные замечания

- Пока без авторизации: не открывай наружу в интернет без reverse proxy + auth.
- Для production сейчас поднимается API `web`, а React обычно лучше собирать в статик и отдавать через nginx/caddy (сделаем отдельным шагом).
