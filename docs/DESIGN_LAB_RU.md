# Примерочная TeamTime

Основной интерфейс теперь использует Studio: http://localhost:5173/. Детали переноса и проверки — в [STUDIO_MIGRATION_RU.md](STUDIO_MIGRATION_RU.md).

Отдельная примерочная сохранена: http://localhost:5173/design-lab?view=compare

Три концепции построены на существующем React/Vite. Для обновлённого Studio подключён локальный вариативный шрифт Golos Text (`@fontsource-variable/golos-text`), включая кириллицу; шрифт отдаётся самим приложением.

| Вариант | Ссылка | Основной акцент |
| --- | --- | --- |
| Studio | http://localhost:5173/design-lab?concept=studio | Светлый кабинет, Golos Text, узкая боковая панель с подписями, календарь и баланс команд |
| Arena | http://localhost:5173/design-lab?concept=arena | Графит, лайм, крупная спортивная типографика, ближайшая игра и результаты |
| Club | http://localhost:5173/design-lab?concept=club | Кремовый фон, терракота, антиква, встречи и участники сообщества |

Верхняя панель переключает концепции, открывает сравнение, включает узкий предпросмотр и сохраняет фаворита в localStorage. Ссылки содержат выбранную концепцию; работают обновление страницы и история браузера.

В каждой концепции доступны все девять разделов продукта, кроме документации:

| Раздел | Что можно примерить |
| --- | --- |
| Обзор | Метрики, календарь, ближайшая встреча, баланс команд |
| События | Карточки, запись и отмена, создание демособытия |
| Игроки | Портреты и игровые номера, сильные стороны, карточки/список, позиции, поиск и сортировка, подробный профиль, пример расстановки на площадке |
| Игры | Журнал партий, счёт, фильтр по событию, раскрывающиеся составы |
| Голосования | Статусы, результаты, ответы участников, поиск и фильтры |
| Задолженности | Список игроков с портретами и выровненными суммами, раскрывающиеся взносы по встречам, оплата одного или всех взносов с отменой, выбор получателей и предпросмотр напоминания |
| Шаблоны голосований | Список, создание и редактирование, варианты ответа и их веса, живой предпросмотр |
| Шаблоны событий | Список, создание и редактирование; вкладки «Основное», «Расписание», «Правила» |
| Мой профиль | Роль, история встреч, задолженность, назначение клубных ролей в демо |

Раздел сохраняется в query-параметре `screen`, например `/design-lab?concept=studio&screen=games`. Работают обновление страницы и переходы назад/вперёд. Диалоги закрываются Escape.

В Studio сохранены светлая палитра и структура обзора. Увеличены шрифт и подписи; название клуба и организатор перенесены в шапку. Полное меню занимает 108 px (100 px на небольших планшетах); длинные подписи переносятся на две строки. На телефоне все девять разделов показаны сеткой 3 × 3. Стили Studio находятся в `studio.css`, полное меню и дополнительные экраны — в `product-screens.css`.

Данные вымышленные: предстоящая неделя 14–20 сентября 2026 и история предыдущих встреч. Изменения не обращаются к API и не отправляются в Telegram. Шаблоны, роли и отметки оплат сохраняются в памяти при переходах между разделами; данные демо сбрасываются при смене концепции или перезагрузке. Фаворит сохраняется отдельно. Подбор команд иллюстрирует интерфейс и не вызывает реальный алгоритм ML. Предпросмотр напоминания не публикует сообщение.

Страница игроков обновлена отдельной итерацией: фотографии из единого атласа 3 × 2, игровые номера, акценты по позициям, сравнение подачи/приёма/атаки, подробные навыки и посещаемость в профиле. Фильтр ближайшей игры показывает пять из шести демопрофилей. Кнопка «На площадке» открывает иллюстрацию расстановки с переходами в профили. Все портреты вымышлены и созданы встроенным imagegen; файл и точный промпт описаны в `web/public/design-lab/roster-portraits-v1.prompt.md`.

Задолженности оформлены единым списком: портрет и имя слева, сумма, выбор для напоминания и оплата — в выровненных колонках. Нажатие на игрока раскрывает таблицу взносов; у Дмитрия детализация открыта по умолчанию. Название встречи и дата сгруппированы, размер названий — 14–16 px, сумм — 17–18 px. У каждого взноса показан статус и отдельная кнопка оплаты; после оплаты доступна отмена. На телефоне кнопка занимает всю ширину строки. Общая сводка показывает остаток, число игроков и неоплаченных взносов. Узкая панель под списком показывает выбранных получателей и сумму напоминания. Доступны поиск, сортировка, фильтры «С задолженностью», «Все игроки», «Без долга» и отмена последнего изменения оплаты. На телефоне сумма остаётся рядом с именем, действия переносятся на вторую строку. Экран и стили находятся в `DebtsScreen.tsx` и `debts.css`; общий компонент портрета используется также на странице игроков.

## Локальный запуск

Команды из корня TeamTimeBot:

```powershell
docker compose up -d --build db ml web frontend
docker compose exec web /migrate -dir /migrations up
```

Frontend: http://localhost:5173. API: http://localhost:8080. Healthcheck API: http://localhost:8080/healthz.

Бот запускается отдельно после задания `BOT_TOKEN` в локальном `.env`:

```powershell
docker compose up -d bot
```

Для обновления интерфейса при редактировании через bind mount Docker Desktop включён polling Vite. Проверка TypeScript и сборки:

```powershell
docker compose exec frontend npm run build
```

Исходный интерфейс доступен по `/`; в боковом меню добавлена ссылка на примерочную. При пустом ответе API (`null`) список организаций теперь корректно преобразуется в `[]`.

## Что показал graphify

Карта исходного проекта: `web/graphify-out/graph.json`, интерактивная версия `graph.html`, отчёт `GRAPH_REPORT.md`. Снимок сделан перед реализацией примерочной: 125 файлов, 1 118 узлов, 2 428 связей, 71 сообщество.

TeamTime объединяет React-кабинет, Go API, Telegram-бота, PostgreSQL и Python-сервис подбора команд. Центральный пользовательский сценарий: событие → голосование/запись → распределение игроков → партии → расчёт оплаты. Поэтому во всех концепциях показаны реальные предметные сущности: события, навыки и позиции, составы, счёт и взносы.

Переход graphify по `split_teams`, `autoSplitEventTeams` и `MemberSkillProfile` связывает `ml/server.py`, `web/src/api.ts`, `web/src/App.tsx` и хранение навыков в `internal/storage/postgres/store_members.go`. Старые README и часть документации относятся к раннему этапу проекта; структура сверена с текущими исходниками и Docker Compose.

Точные токены и стоимость семантического извлечения недоступны в метаданных агента; в отчёте это отмечено явно.

## Проверка

- `npm run build`: TypeScript и production-сборка.
- Ручная проверка в браузере: все концепции на широком экране и при ширине 390 px, поиск и пустое состояние, запись/отмена, создание события, оплаты и фильтр долгов, сравнение и избранное.
- Полное меню сверено с `src/app/navigation.tsx`: девять разделов, документация исключена. Проверены переходы по всем разделам Studio, мобильный предпросмотр 402 px, редактор с живым предпросмотром, сохранение шаблонов между переходами, пересчёт долга и предпросмотр напоминания. В Arena и Club проверены полное меню и новые экраны при узкой ширине.
- Запущены PostgreSQL, ML, Go API и frontend; выполнены все 38 миграций.
- Обновлённые задолженности: проверены отдельная и полная оплата, отмена, пересчёт итогов и фильтров, выбор получателей, предпросмотр сообщения, пустой поиск и состояние без долгов. Визуально проверены Studio при ширине 1536 px и мобильном предпросмотре 402 px, включая диалог, а также широкие Arena и Club; переполнения карточек нет.

- Итерация списка задолженностей: проверены раскрытие и сворачивание строк, отдельная и общая оплата с отменой, фильтр всех игроков и выбор получателей. Список проверен в Studio на широком экране 1536 px и мобильном предпросмотре 402 px; переполнения строк нет.

- Читаемость раскрытых взносов: проверены группировка названий и дат, статусы оплаты и отмена, широкая раскладка 1536 px и мобильная 402 px без горизонтального переполнения.
