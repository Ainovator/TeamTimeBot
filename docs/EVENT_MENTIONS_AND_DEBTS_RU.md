# Упоминания и задолженности

В карточке события откройте **Оплата → Опубликовать задолженность**. Предпросмотр показывает неоплаченные взносы только этой тренировки. Можно исключить игроков из сообщения; при пустом выборе публикация недоступна. Изменённые отметки оплаты нужно предварительно сохранить. Перед открытием предпросмотра приложение повторно загружает оплаты, а сервер перед отправкой исключает уже оплативших игроков.

В разделе **Взносы** и при публикации задолженности отдельной тренировки имена игроков отправляются как упоминания Telegram по ID. Наличие публичного `@username` не требуется. Реальную доставку уведомления определяет Telegram и настройки пользователя. Формат соответствует [документации Telegram Bot API](https://core.telegram.org/bots/api#formatting-options).

В **Организация → Шаблоны событий** при создании или редактировании шаблона есть блок **Кого упоминать**. Выберите игроков через поиск или кнопку выбора всех. Один список используется для опроса и напоминания; для каждого вида сообщения есть отдельный переключатель. При пустом списке упоминания не отправляются. Настройки действуют и для ручной публикации, и для расписания.

После публикации опроса бот отправляет список упоминаний ответом на этот опрос. В анонсе упоминания добавляются в конец сообщения. Перед отправкой проверяется актуальное членство в организации; выбывшие игроки исключаются. Если сам опрос уже опубликован, а отправка упоминаний завершилась ошибкой, приложение сообщает об этом отдельно.

## Обновление сервера

Миграция `00039_event_mentions.sql` добавляет список Telegram ID и два переключателя в `group_events`. Сначала примените миграции, затем обновите веб-сервер и процесс бота. У существующих шаблонов список пустой, поэтому обновление само по себе никого не тегает.

Публикация долга конкретного события использует `POST /api/groups/{chatID}/events/history/{instanceID}/billing/publish` и право `billing_manage`. Список кандидатов для упоминаний доступен через `GET /api/groups/{chatID}/events/mention-recipients` с правом `event_templates_manage`.

## Проверка

`go test ./internal/... ./cmd/...` проверяет сервер и подготовку сообщений. Для интеграционных проверок задайте `TEAMTIME_TEST_DATABASE_URL` на отдельную PostgreSQL: тест создаёт временную схему, применяет миграции и удаляет только свою схему. Telegram заменён транспортом в памяти; сообщения не отправляются в сеть. Проверяются выбранная тренировка, исключение оплативших и чужих игроков, упоминания без username, HTML-экранирование, длинные списки, сохранение и очистка настроек, отключённые режимы и выбывшие участники.
