# Публичный лендинг TeamTime

- `/` и `/landing` открывают лендинг независимо от наличия сессии.
- `/app` открывает существующее приложение и его авторизацию; `/org/…` продолжает работать как раньше.
- Лендинг загружается отдельно от CSS и JavaScript кабинета, не запрашивает API и не изменяет настройки темы пользователя.
- CTA ведут в существующий вход. Здесь нет формы заявки, платёжной формы или обещания самостоятельного создания организации.
- Семь возможностей расположены в согласованном порядке. Скриншоты увеличиваются в диалоге; поддержаны Escape, возврат фокуса и управление вкладками стрелками, Home/End.
- Число «10 спортивных команд» предоставлено владельцем продукта.

## Изображения

`public/landing/*.png` — снимки локального интерфейса при ширине 1360 и высоте 920, снятые 23.09.2026. Использованы только демонстрационные данные организации «Орбита · тестовая команда» (`-900001`). Все снимки встроены как статические файлы; доступ посетителя к API этой организации не требуется.

- `events.png`: События → список.
- `votes.png`: событие 10 сентября → Голоса; используется также для объяснения связи с Telegram.
- `billing.png`: Взносы за события.
- `passes.png`: Абонементы.
- `games.png`: Игры.
- `players.png`: Игроки → карточки.

Карточка встречи на первом экране — иллюстрация на HTML/CSS, подписанная «Пример встречи в TeamTime».
